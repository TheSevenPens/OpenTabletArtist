# OpenTabletArtist

An alternative experience for [OpenTabletDriver](https://opentabletdriver.net/) 

## Try it now

**[Read the documentation](https://docs.sevenpens.com/opentabletartist)**
for setup, user guides, and troubleshooting.

## Record strokes for StrokeCorpus

In Scribble, use **Record** to save a recording. Give it a name that describes
the stroke pattern. [StrokeCorpus](https://github.com/TheSevenPens/StrokeCorpus)
groups familiar names by stroke type. Unfamiliar patterns appear under **Other**
and keep the name you entered.
