## What's new

- **Cards are flatter.** Sections lost their chrome entirely, and list items became a
  lighter row style — less boxing, more content.
- **Two-column layouts** for the tablet Controls tab and the Appearance tab.
- **The Developer tab is always shown,** and the separate Dev Tools tab is gone.
