## What's new

- **A "Don't use Windows Ink" mouse-compatibility mode.** Some applications behave badly
  with Windows Ink; this switches the pen to plain mouse input without you having to go
  hunting through OpenTabletDriver's settings. It is independent of the movement mode, so
  the two no longer interfere.
- **An Information tier for health checks,** for things worth telling you that aren't
  problems.
