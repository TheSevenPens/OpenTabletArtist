## What's new

- **The OpenTabletDriver pages are one hub now,** with tabs, instead of being scattered
  through the navigation.
- **A Startup page** under Advanced.
- **Calibration is built around three point-count choices,** each on its own card, so
  picking how thorough a calibration you want is the first thing you do.
- **Home shows less about the driver,** with the full detail moved to its own page.
- **Pen Inputs is reordered and renamed,** and its pen diagram is fixed.

## Renamed

Test Drawing is now **Scribble**, EXPRESSKEYS is now **BUTTONS**, and WHEEL is now
**WHEELS**.

## Fixed

- **Quit asks first, and exits cleanly** instead of leaving a process behind.
- Fonts are consistent across the app.
- The Display Mapping diagram lost its live tracking dot, which added nothing.
