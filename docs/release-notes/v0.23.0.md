## What's new

- **Per-app profile switching happens on its own,** with a floating toast telling you
  when it switched and to what.
- **Pen Dynamics is always on internally,** so the on/off toggle is gone — it only ever
  created a state where your curve was configured but not applied.

## Fixed

- **An infinite save loop** started by the Pen Behavior movement toggle. There is now a
  guard against runaway settings applies generally, so a loop like that can't run away
  with the app again.
