## What's new

**Driver cleanup names the Wacom driver packages behind OpenTabletDriver's warning.**
OpenTabletDriver's Wacom check only says the word turned up somewhere in the installed
drivers, never which one, so the card gave you nothing to act on. When that warning is
raised, the Driver cleanup page now lists the third-party driver packages whose provider or
file name matches, under a heading that says removing them is optional. It reads the
Windows driver store directly, so it needs no elevation. No other drivers are looked up.

**The Supported tablets list says which OpenTabletDriver it comes from.** Its heading
reads "OpenTabletDriver 0.6.7 supports these tablets", because the list is that release's
own catalog.

**The Advanced page's Diagnostics tab is hidden until you want it.** It is a developer
view, so it no longer takes up room in the rail by default. To bring it back, open
Settings, Dev, Interface and tick "Show the Diagnostics tab".

## Fixed

- **The "unsaved changes may be lost" warning stayed on screen after the driver
  reconnected.** If the connection dropped while you had unsaved changes, the warning about
  reconnecting reloading your settings was shown, and nothing took it down once the daemon
  was back. It is replaced by the reconnect message now.
- **The conflicting-driver card on Home says Review, not Fix.** Which driver to remove, and
  whether it is a real conflict at all, is your call, so the button opens the Driver
  cleanup page instead of promising a one-click repair.
- **The About text spells the name OpenTabletArtist,** and its Get help link opens the
  help page on the documentation site.

## Also

Scribble's "Report dots" checkbox is now "Mark positions". The Presets page keeps just its
first explanatory paragraph, and the note on the Hotkeys page is down to its one line about
shortcuts working in any application.

Work continues on macOS and Linux, but only the Windows build is released and supported.
