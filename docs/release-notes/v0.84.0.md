## What's new

**Install the .NET 10 runtime before you run OpenTabletArtist.** The app no longer carries its own
copy of .NET, so the download is much smaller. The OpenTabletDriver that comes with it already needed
.NET 10, so one install now covers both. If it isn't installed, a message says "You must install
.NET to run this application" and the app doesn't open; install the **x64 .NET 10 runtime** from
Microsoft, then start it again. Having only .NET 8 or 9 is not enough.

**Load a preset from the tray.** The tray menu has a **Load Preset** submenu listing your saved
presets by name. It asks the same question about unsaved changes that the Presets page does.

**The Presets page shows which preset you last loaded**, can sort by name, and asks before
**Update from current settings** overwrites a preset. Loading a preset no longer pauses editing when
a tablet is plugged in that the preset didn't know about; that tablet keeps its settings.

**A Health tab.** A number on the **Health** tab counts what needs attention and shows how serious the
worst of it is. Home is now About, then your tablets, then your presets, and each section has a
**Details** link to its page. Your tablets are one list, with the plugged-in ones first. If a health
check can't run, the page now says "could not check" instead of staying on "checking" or saying all is
well.

**Reset buttons on the pen sliders**, for softness, deadzone, pressure smoothing, position smoothing
and the hover limit. The **Scribble** page has a link, **Adjust pressure curve and smoothing**, that
opens the Pen page's pressure tab.

**The buttons tab's pen picture is smaller**, the cards no longer repeat their titles, and buttons
that do the same thing share a colour and say which they match.

**The Filters tab moved to Advanced**, still behind the Developer setting. It lists every tablet's
filters, not just one tablet's.

**The app won't attach to a daemon from a different OpenTabletDriver release.** If the major, minor or
patch version differs, or can't be read, it says so instead of carrying on. A difference in the last
part only is allowed with a note.

**Keys in dialogs.** In the rename box Enter is OK and Escape is Cancel. Escape answers No to a yes/no
question, and closes a message.

## Fixed

- Dragging the active area past the tablet's edge could throw an error mid-drag.
- Dragging the pressure curve's bend node to its far end made the curve jump back and forth.
- Renaming a preset to a name Windows doesn't allow, or one containing a slash, could move the file
  somewhere else or throw an error. Changing only the case of a name now works.
- Loading a preset could apply over an edit you made while its question was open, and Update could
  save the older settings.
- The monitor hotkey's Shift variant blocked assigning the same keys to a preset, with no visible cause.
- Saving two recordings at once could fail with "access denied".

## Also

Work continues on macOS and Linux, but only the Windows build is released and supported.
