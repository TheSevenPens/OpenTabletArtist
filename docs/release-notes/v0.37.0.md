## What's new

- **A Copy button on message and error dialogs,** so you can paste an error somewhere
  useful instead of retyping it.

## Fixed

- **Calibration works on display layouts with negative coordinates** — that is, when a
  monitor sits left of or above your primary one. Both the capture and the
  display-matching got this wrong.

## Under the hood

Most of this release is the groundwork for running on macOS: display enumeration, a
build lane, and gating the Windows-only parts. Nothing there is released yet — Windows
remains the only supported platform.
