## What's new

**Saving is something you do now.** Every edit still reaches the driver the moment you
make it, so nothing about drawing changes — but keeping it across a driver restart means
pressing Save. The footer says "Unsaved changes" while there is something to keep and
nothing at all once there isn't, with Save and "Revert to saved" beside it — Save first,
because it is what you want almost every time, and Ctrl+S if you'd rather not reach.

**When something changes the driver's settings underneath you, OTA stops and explains.**
Attaching a tablet OpenTabletDriver hasn't seen before does this, and so does another
settings app. Editing pauses across the whole app, and the page tells you what happened,
what reloading will take from you, and what it can't bring back. It used to be one line at
the very bottom of the window.

**Two editors can no longer overwrite each other silently.** If OTA and something else are
both editing, the one that got there second is told, and you choose what happens rather
than finding out later.

**OTA runs the OpenTabletDriver it ships.** Start launches the bundled driver rather than
whatever it can find by that name, the download carries OpenTabletDriver's own official
build rather than one OTA compiled, and if your machine has no .NET runtime for it, OTA
offers to fetch one — handing the download to your browser, and checking the installer's
signature before running it. You can open OpenTabletDriver's own window from the Daemon
page whenever you want it.

**Connecting says how long it is prepared to wait.** The indicator carries the elapsed
time, the point at which OTA stops waiting in the foreground and keeps trying in the
background, and Start stays available throughout. Asking it to re-check with no driver
running now says so immediately, instead of spending thirty seconds waiting for an answer
that cannot come.

**The mapping tab reads at a glance.** Millimetres and inches are shown together, so
there's no unit toggle to remember; size and rotation share a row; the display list shows
the monitor number and nothing else; and the diagram has a third rail along its bottom
edge so the shape you're editing is easier to place.

## Fixed

- **The active area stops snapping back to where the drag started.**
- **A rotation you pick while another change is still applying is no longer dropped.**
- **Calibration writes go out in order,** and closing calibration takes effect straight
  away instead of queueing behind them.
- **Closing the calibration overlay releases the pen** rather than holding the stream on
  its way out.
- **A refused calibration says it was refused,** instead of inviting you to check a result
  that was never written.
- **The app renders in Inter** — the font it has always named and never once used.
- **An active area that comes back empty is repaired on every path that sends it,** not
  only when saving.
- **The health cards' review links work again.** They had done nothing since 8 September.
- **The Reload confirmation stops promising that your applied changes survive it.** It now
  says they are kept only if the driver still has them, which is all it can know.
- **The "Saved" chip goes away again.**
- **The navigation no longer twitches a pixel when the tablet switcher appears.**
- **The mapping table fits in an 800-pixel window** instead of clipping its measurements.

## Also

The settings footer is 14 pixels shorter, the health-check wording is shorter, the plugins
page no longer names the Windows Ink plugin's author, and text that means
OpenTabletDriver's background process says "OTD daemon" consistently.

Work continues on macOS and Linux, but only the Windows build is released and supported.
