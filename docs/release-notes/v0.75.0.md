## What's new

**The Daemon page leads with the connection it is describing.** Everything on that page
is a fact about one relationship — OpenTabletArtist talking to a separate
OpenTabletDriver process — and it used to be laid out as four unrelated property lists
that hid this.

It now opens with a diagram you read top to bottom: this app, the connection running
beside its own details, then the driver process. Restarting the driver shows the box go
solid while the connection is still coming up, which the old layout couldn't show at
all.

Two rows that both said "Status" answered different questions — is there a connection,
is there a process — and are now visibly different things. The version comparison that
used to need its own row only appears when there's actually a mismatch.
