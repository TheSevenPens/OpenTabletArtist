## What's new

**The Pen page's buttons tab makes use of the whole window.** The buttons used to be squeezed
into a narrow column beside a rotated pen. Now the pen lies across the top with its buttons
numbered from the tip, and each button has its own card underneath. When the window is wide
enough the cards sit side by side with a line from each button on the pen to its card, so
which card is which button is a line to follow. In a narrow window the cards stack and the
lines go. A pen with a single button gets one half-width card.

**The three choices are always in view.** Each card shows **Default action**, **Keyboard
shortcut** and **Disabled** side by side, with the current one highlighted, instead of hiding
them behind a **…** menu. Under the choice, the card says what it means: the Barrel Switch and
who decides what it does, a recorded shortcut drawn as keys with a **Change…** button, or
"Does nothing". Closing the shortcut editor without saving leaves the button as it was.

**The pen is drawn from the real pen outline.** The picture now has the pen's swelling grip,
tapered nib and eraser seam in place of the old hand-drawn shapes.

## Also

Nothing about what is written to OpenTabletDriver changes: the same three choices write the
same bindings as before, and a button set somewhere else still shows what it does now, with a
warning where it does not suit Windows Ink, until you pick something.

Work continues on macOS and Linux, but only the Windows build is released and supported.
