## What's new

- **OTA picks up settings changed outside it.** Edit something in OpenTabletDriver's own
  window and OTA now follows, instead of showing stale values until you restart.
- **Theming gained a card colour and a custom base colour,** with clearer controls and a
  reset.
- **Plugins are shown as cards,** and the Log tab is now called Console.
- **Tablet settings** gained a display-mapping button row, a calibration status card, and
  a two-column layout for buttons.

## Fixed

- **Display mapping is correct when your primary monitor isn't the top-left one** —
  including duplicated displays, which used to map to the wrong place entirely.

## Renamed

The monitor-cycle hotkey is now **Display toggle**, and Display Mapping's Refresh button
is now **Refresh Display Settings**, so it is clear what it refreshes.
