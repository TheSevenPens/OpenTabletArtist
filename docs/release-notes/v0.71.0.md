## What's new

- **Every "Fix" button actually fixes.** Some health checks offered a Fix that only took
  you to the setting; they now make the change, and a separate Review button is there
  when you want to look first.
- **One colour picker, everywhere.** The two different pickers are now a single tabbed
  control, built around a hue ring and a saturation/value triangle.
- **The pen's movement tab is now "Basics",** in two columns, with the Windows Ink choice
  as a radio group under Pressing — so the options read as the alternatives they are.
- **A new app icon** and a black-and-white mark on Home.

## Fixed

- **Picking displays quickly no longer confuses the mapping.** Rapid changes are applied
  in order and collapsed to the last one you chose.
- **A copy that fails tells you,** instead of quietly doing nothing and leaving you to
  paste stale clipboard contents.
- **Stopping the daemon on Linux goes through systemd** where systemd started it, rather
  than killing anything with a matching name.
- **Invalid colour codes in the gradient editor are rejected** instead of being stored.

## Accessibility

- **Keyboard support for the mapping diagram and the pressure softness control,** which
  were mouse-only.

The user documentation was rewritten throughout for clarity.
