## What's new

- **An ABOUT tab on each tablet's page,** with the area measurements.
- **Metric or imperial,** your choice, on the Active Area tab.
- **Wacom-style corner-mapping lines** on the display diagram, so you can see which
  corner of the tablet goes where.
- **Invalid display mappings are flagged** on the tablet page and on Home, rather than
  silently doing something strange.
- **A Developer tab** under Advanced.

The window title now says BETA, which it is.
