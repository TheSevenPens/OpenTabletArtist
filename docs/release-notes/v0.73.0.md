## What's new

**A diagnostics log for the failures OTA used to swallow.** A lot of background work —
loading presets, deleting configs, looking up plugins, starting the driver, switching
per-app profiles — used to fail silently, so a thing that "just didn't work" left no
trace at all. Those failures are now recorded to a log you can read or send on.

## Fixed

- **OTA could write a profile that crashed OpenTabletDriver's own window when you
  pressed Save,** by leaving an Absolute-mode area empty. It can't any more.
- **Deleting a configuration now tells you if it failed,** instead of appearing to work.
- **Corrupted settings and missing plugins are reported** rather than quietly ignored.
