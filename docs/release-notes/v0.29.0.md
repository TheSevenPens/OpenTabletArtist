## What's new

- **A supported-tablets list inside the app** — no more going to the website to find out
  whether your tablet is supported. Filter by brand, sort the columns, and read the
  status and notes for each one.
- **The theme reaches the top edge of the window** now, under the title bar.

## Changed

- **Filters that aren't approved are disabled by default.** OpenTabletDriver plugins can
  degrade pen behaviour in ways that are hard to attribute, so they now start off.
