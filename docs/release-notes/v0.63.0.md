## What's new

- **The Daemon page is rebuilt into focused cards,** each answering one question.

## Linux

Initial Linux support, though the released download is still Windows only:

- The Daemon tab shows whether OpenTabletDriver is installed as a system package, with a
  button to start it.
- An application-menu entry, the Linux equivalent of a Start-menu shortcut.
- Relaunching brings the running window forward instead of doing nothing.
- A hint when the tray icon can't be shown, which is normal on GNOME.
- A standalone setup tool that checks the things Linux needs and explains what to fix.
