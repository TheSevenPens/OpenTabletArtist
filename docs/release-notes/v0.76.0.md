## What's new

**OpenTabletArtist now sets up OpenTabletDriver for you.** It ships the official
OpenTabletDriver release, installs it if you don't have one, and finds and adopts an
existing install if you do. If you point it at a folder yourself, it remembers.

**It tells you when the driver isn't the one it expects.** Running a different
OpenTabletDriver version now shows as a health warning rather than failing in some
confusing way later, and the Daemon page shows exactly which driver you're connected to
and where it lives.

**The Daemon page is one page again.** One card for the driver you're connected to,
laid out in two columns, with every health problem listed in one place instead of
scattered across three cards saying overlapping things.

## Fixed

- **Your settings can no longer be lost to a failed or interrupted save.** Writes are
  now atomic with a last-known-good backup, so a crash or a locked file leaves your
  previous settings intact instead of an empty file.
- **A save that fails now says so, and retries.** It used to report success and go
  quiet, which meant a change could look applied and then vanish on the next restart.
- **Running two OpenTabletDriver installs no longer risks crossing their settings.**
  Switching between them can't write one's settings into the other's file.
- **Per-app profile switching applies the profile it says it did** — and says so
  honestly when the driver refused it.
- **Home no longer says "Nothing needs attention" beside a warning.**
- **OTA asks before stopping a driver it didn't start,** instead of stopping anything
  it finds by that name.
- **A tablet settings window you've closed can no longer write settings afterwards.**

## Also

The download is smaller — 87 MB to 50 MB — because OTA now ships OpenTabletDriver's
official build rather than one it compiled itself.

Work continues on macOS and Linux (detecting why a tablet isn't found, installing the
driver, adopting an existing one), but only the Windows build is released and supported.
