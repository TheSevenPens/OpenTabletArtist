## What's new

- **Picking a display maps to it immediately.** The Apply button is gone — it was a
  second step that only ever meant "yes, I meant it".
- **The mapping diagram shows off-screen and custom mappings** instead of drawing
  something misleading.
- **A health warning when the active area is rotated to an odd angle,** which is almost
  always a mistake.
- **Each wheel is a single card,** without nested cards inside it.

## Fixed

- **The wheel sensitivity slider stops snapping back to the minimum.**
- **Adjacent displays are drawn touching,** not with a gap that doesn't exist.
