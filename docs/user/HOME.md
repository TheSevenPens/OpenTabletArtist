# Home page

*(Part of the [User Manual](USERMANUAL.md).)*


The homepage will tell you if you need to do anything. The "Needs Attention" section will provide a list of things you should be aware of, and most of the time, it will give you an option to either fix or review something that is unusual. This might be an unusual configuration of settings or something not being installed correctly. As long as the "Needs Attention" section is clear and you don't see anything there, there's nothing wrong that you need to be worried about. But if you do see something here, pay attention. Below "Needs Attention," you'll see a list of tablets that have been connected to OpenTabletDriver, and it will tell you if those tablets are currently connected.

Each tablet card also shows which display its active area is mapped to (for example, "Mapped to Display 1"). If the tablet isn't mapped cleanly to a single display — a custom area, part of it off-screen, or no mapping — the card says "needs attention" instead, so you know to open its settings and fix the mapping. This line updates automatically when you plug in or unplug a monitor. **Double-click a tablet card to open its settings**, and use the trash icon to forget a remembered tablet (or reset a connected one to defaults).
