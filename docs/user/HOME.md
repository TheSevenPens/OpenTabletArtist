# Home page

*(Part of the [User Manual](USERMANUAL.md).)*

Home is laid out in two columns. **Needs attention** is the right-hand column; **About** and **Your tablets** run down the left.

The homepage will tell you if you need to do anything. **Needs attention** will provide a list of things you should be aware of, and most of the time, it will give you an option to either fix or review something that is unusual. This might be an unusual configuration of settings or something not being installed correctly. When there's nothing wrong, the column says **Nothing needs attention** — so an all-clear looks like an all-clear rather than like a column that failed to load. But if you do see something here, pay attention.

Under **Your tablets** you'll see a list of tablets that have been connected to OpenTabletDriver, and it will tell you if those tablets are currently connected.

Each tablet row also shows which display its active area is mapped to (for example, "Mapped to Display 1"). If the tablet isn't mapped cleanly to a single display — a custom area, part of it off-screen, or no mapping — the row says "needs attention" instead, so you know to open its settings and fix the mapping. This line updates automatically when you plug in or unplug a monitor. **Double-click a tablet row to open its settings** — or use the row’s **⋯** menu, which offers the same by name, plus **Forget this tablet** to drop a remembered one (or reset a connected one to defaults).

**About**, at the top of the left column, says what OpenTablet Artist is and which version you're running, alongside links to [getting help](HELP.md), the supported-tablets list, the source code, releases, and this manual.
