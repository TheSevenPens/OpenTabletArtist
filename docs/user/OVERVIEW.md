# Introduction to OpenTabletArtist (OTA)

OTA is an alternative user experience for OpenTabletDriver (OTD) that prioritizes the needs of artists: to get set up quickly, in a familiar environment, so they can be productive with their creative apps.

OTA is currently Windows only.

## How OTA Works

OTA is another user interface that talks to the OpenTabletDriver daemon, which is the actual tablet driver.

## Key Benefits of OTA

OTA is optimized for artists and works more like familiar drawing tablet drivers. If you've used the Wacom driver, OTA should feel more natural than OTD.
